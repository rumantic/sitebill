# Добавление галочки согласия на обработку персональных данных

Руководство по настройке чекбокса согласия на обработку персональных данных (GDPR compliance) в формах CMS Sitebill.

## Описание

В системе предусмотрена встроенная функция добавления чекбокса согласия на обработку персональных данных для форм. Это реализуется через настройки конфигурации системы, без необходимости редактирования формы.

## Где активируется

Настройки находятся в административной панели:  
**Конфигурация → Настройки → Раздел "Формы"**

## Доступные параметры

### 1. Активация соглашения

**Параметр**: `post_form_agreement_enable`  
**Тип**: Чекбокс (да/нет)  
**Описание**: Активировать выдачу соглашения после формы

При включении этой опции:
- В конце формы добавляется чекбокс с текстом соглашения
- Кнопка отправки формы блокируется до тех пор, пока пользователь не поставит галочку
- Реализована автоматическая JavaScript-валидация

### 2. Текст соглашения

**Параметр**: `post_form_agreement_text_add`  
**Тип**: Текстовое поле  
**Значение по умолчанию**: "Я, ознакомлен(а) с Пользовательским соглашением"  
**Описание**: Текст, который будет отображаться рядом с чекбоксом

В тексте можно использовать HTML-теги для создания ссылок на документы:
```html
Я ознакомлен(а) с <a href="/agreement" target="_blank">Пользовательским соглашением</a> и даю согласие на обработку персональных данных
```

### 3. Режим отображения (уведомление)

**Параметр**: `post_form_agreement_enable_note`  
**Тип**: Чекбокс (да/нет)  
**Описание**: Выводить соглашение с формой в виде текстового уведомления

Если эта опция включена:
- Вместо чекбокса отображается текстовое уведомление
- Кнопка отправки не блокируется
- Используется текст из языковой константы `L_AGREEMENT_TEXT_FORM_NOTE`

## Быстрая настройка (через админку)

1. Зайдите в административную панель
2. Перейдите в **Конфигурация → Настройки**
3. Найдите раздел **"Формы"**
4. Установите галочку **"Активировать выдачу соглашения после формы"**
5. Введите текст соглашения в поле **"Текст соглашения после формы добавления объявления"**
6. Сохраните настройки

## Настройка через SQL

Опционально, параметры можно задать напрямую через SQL-запросы:

```sql
-- Активировать соглашение
UPDATE config SET value = '1' WHERE name = 'post_form_agreement_enable';

-- Установить текст соглашения
UPDATE config SET value = 'Я согласен с условиями обработки персональных данных' 
WHERE name = 'post_form_agreement_text_add';

-- Активировать режим уведомления (опционально)
UPDATE config SET value = '1' WHERE name = 'post_form_agreement_enable_note';
```

## Пример реализации

### HTML-код, генерируемый системой

При включенной опции система автоматически генерирует следующий код:

```html
<div class="agreement_form_block">
    <input type="hidden" name="agreement_el" value="1">
    <div class="agreement_form_block_input">
        <input id="agreement_form_block_input_xxxxx" type="checkbox" name="agreement" value="1">
    </div>
    <label for="agreement_form_block_input_xxxxx">
        Я ознакомлен(а) с Пользовательским соглашением
    </label>
</div>
```

### JavaScript-валидация

Автоматически подключается скрипт для блокировки кнопки отправки:

```javascript
$(document).ready(function(){
    // Блокируем кнопку отправки, если чекбокс не отмечен
    if(!$("#i_am_agree_in_form").is(":checked")){
        $("#formsubmit").prop("disabled", true);
    }
    
    // Отслеживаем изменение чекбокса
    $("#i_am_agree_in_form").change(function(){
        if($(this).is(":checked")){
            $("#formsubmit").prop("disabled", false);
        }else{
            $("#formsubmit").prop("disabled", true);
        }
    });
});
```

## Локализация (мультиязычность)

Для мультиязычных сайтов можно использовать языковые константы вместо текста из конфигурации:

### Для режима чекбокса
Создайте константу `L_AGREEMENT_TEXT_FORM` в языковых файлах  
Например: `/apps/language/site/lang/ru_RU.php`

```php
$apps_words['system']['L_AGREEMENT_TEXT_FORM'] = 'Я согласен с <a href="/agreement">Политикой конфиденциальности</a>';
```

### Для режима уведомления
Создайте константу `L_AGREEMENT_TEXT_FORM_NOTE` в языковых файлах

```php
$apps_words['system']['L_AGREEMENT_TEXT_FORM_NOTE'] = 'Отправляя форму, вы соглашаетесь с условиями обработки персональных данных';
```

Система автоматически выберет нужный язык на основе текущей локали.

## Техническая реализация

### Основной метод

За генерацию блока согласия отвечает метод:

```php
Form_generator::getAgreementFormBlock()
```

**Расположение**: `/apps/system/lib/system/form/form_generator.php` (строки 5438-5470)

### Логика работы

1. Метод проверяет параметр `post_form_agreement_enable_note`
2. Если включен режим уведомления — выводит текстовый блок
3. Если включен режим чекбокса — генерирует HTML с `<input type="checkbox">`
4. Использует декоратор формы для оформления (`form_decorator`)
5. Поддерживает мультиязычность через константы `Multilanguage`

### Интеграция в формы

Формы вызывают метод следующим образом:

```php
if ($this->getConfigValue('post_form_agreement_enable') == 1) {
    $agreement_block = $this->getAgreementFormBlock();
    // Вывод $agreement_block в шаблон
}
```

## Рекомендации по использованию

### 1. Юридическая корректность
- ✅ **Всегда указывайте ссылку** на страницу с Пользовательским соглашением или Политикой конфиденциальности
- ✅ Убедитесь, что текст соглашения соответствует законодательству (GDPR, 152-ФЗ)
- ✅ Храните информацию о согласии пользователя в базе данных

### 2. UX и читаемость
- ✅ **Используйте понятный текст**, избегайте юридического жаргона
- ✅ Делайте текст коротким, но информативным
- ✅ Используйте активные ссылки на полный текст документов

### 3. Мультиязычность
- ✅ **Для мультиязычных сайтов** настройте языковые константы
- ✅ Убедитесь, что ссылки на документы ведут на версию на соответствующем языке

### 4. Тестирование
- ✅ **Тестируйте формы** после включения опции на всех страницах сайта
- ✅ Проверьте работу в разных браузерах
- ✅ Убедитесь, что кнопка действительно блокируется без галочки

### 5. Примеры хорошего текста

```html
<!-- Для российских сайтов (152-ФЗ) -->
Я согласен на <a href="/privacy" target="_blank">обработку персональных данных</a> в соответствии с политикой конфиденциальности

<!-- Для европейских сайтов (GDPR) -->
I agree to the <a href="/privacy-policy" target="_blank">Privacy Policy</a> and <a href="/terms" target="_blank">Terms of Service</a>

<!-- Для универсального использования -->
Отправляя форму, я принимаю условия <a href="/agreement" target="_blank">Пользовательского соглашения</a>
```

## Расширенная настройка

### Добавление дополнительных чекбоксов

Если нужно добавить несколько чекбоксов (например, согласие на рассылку), можно доработать форму через хуки или напрямую в шаблоне:

```smarty
{* В Smarty-шаблоне формы *}
{if $post_form_agreement_enable}
<div class="agreement_form_block">
    <label>
        <input type="checkbox" name="agreement" value="1" required>
        {$post_form_agreement_text_add}
    </label>
</div>
<div class="agreement_form_block">
    <label>
        <input type="checkbox" name="subscribe_newsletter" value="1">
        Я хочу получать новости и специальные предложения
    </label>
</div>
{/if}
```

### Валидация на стороне сервера

Для проверки согласия на сервере добавьте валидацию:

```php
// В обработчике формы
if ($this->getConfigValue('post_form_agreement_enable') == 1) {
    if (empty($_POST['agreement']) || $_POST['agreement'] != '1') {
        $this->error[] = 'Необходимо согласиться с условиями обработки персональных данных';
        return false;
    }
}
```
